# 🎖️ MIL-DICT | 초급 간부용 군사용어 및 약어 사전

임관 직후 야전 부대와 행정실에 배치된 **초급 간부(소위·중위·하사·중사)**가 실무에서 가장 먼저 부딪히는 군사용어, 영문 약어, 표준 보고체, 무전·작전 유틸리티를 한곳에 모은 웹 애플리케이션입니다.

## ✨ 주요 기능
1. **초급간부 핵심 군사용어·약어 사전**
   - 작전·훈련, 정보·보안, 인사·행정, 군수·장비, 통신·체계, 지휘·일반 6개 분야 수록
   - 용어별 **실무 핵심 팁(선배의 조언)**, **실전 예문**, **연관 용어**, **북마크 / 암기 완료 체크 및 숙달률 게이지**
   - **신규 용어 제보** 및 **동료·선배 간부 한줄 노하우 공유**
2. **실전 보고체 변환 가이드 & 보고문 자동 생성기**
   - 사회 말투 vs 군 표준 보고체 1:1 비교
   - 긴급·우발상황 / 환자 발생·후송 / 당직근무 결산 / 장비 결함 4종 보고 전문 자동 생성 및 원클릭 복사
3. **야전 통신·작전 유틸리티**
   - **NATO 포네틱 코드 변환기** + Web Speech API 음성 읽기
   - **군사시간(DTG, Kilo)** 변환기 및 **작전개시시각(H-Hour)** 계산기
4. **참모부(S-1~S-6) · 제대별 부대기호 · 군수품 1~10종 도감**
5. **역량 테스트 퀴즈 & 실시간 명예의 전당(리더보드)**

## ⚡ Supabase 연동 방법 (실시간 클라우드 DB)
1. [Supabase](https://supabase.com)에서 새 프로젝트를 생성합니다.
2. **SQL Editor** 메뉴로 이동하여 이 저장소의 `supabase_schema.sql` 파일 전체 내용을 붙여넣고 **Run** 합니다.
3. **Project Settings → API**에서 `Project URL`과 `anon public` 키를 복사합니다.
4. 웹사이트 우측 상단의 **`Local Mode` 배지**를 클릭해 URL과 Anon Key를 입력하고 **[저장 및 연결 테스트]** → **[기본 용어 DB 일괄 업로드]**를 누릅니다.
   - *(선택)* GitHub Pages 배포 시 모든 방문자가 별도 입력 없이 바로 연결되게 하려면 `supabase-client.js` 상단의 `DEFAULT_SUPABASE_CONFIG`에 URL과 Anon Key를 입력해 커밋하세요.

## 🚀 GitHub Pages 배포 방법
1. GitHub에 새 Public Repository를 생성하고 본 폴더의 모든 파일을 업로드(Push)합니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Source**를 `Deploy from a branch`, **Branch**를 `main` / `/ (root)`로 설정하고 **Save**를 누릅니다.
4. 1~2분 후 생성되는 `https://<사용자명>.github.io/<저장소명>/` 주소로 접속합니다.
