⚡ Supabase 클라우드 DB & GitHub 연동 센터

왜 Supabase를 연결하나요?

Supabase를 연결하면 신규 제보 용어, 선배 간부 실무 팁 댓글, 퀴즈 명예의 전당 랭킹이 모든 사용자와 실시간으로 클라우드 DB에 공유됩니다.

📋 3분 세팅 체크리스트 (GitHub Pages + Supabase)

  1. Supabase: 새 프로젝트 생성 → SQL Editor에서 supabase_schema.sql 실행
  2. 키 입력: Project Settings → API에서 URL과 anon public 키를 위 입력란에 붙여넣고 연결
  3. GitHub 배포: 저장소에 전체 파일 업로드 → Settings → Pages에서 main 브랜치 배포
